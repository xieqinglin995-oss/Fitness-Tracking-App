# 好好健身 V1.2 体验优化与调研

日期：2026 年 11 月 12 日  
目标：让称重、安排训练、边练边记、回看变化和找回数据形成顺畅的日常流程。

## 本轮设计原则

先减少重复输入和上下文切换，再补齐有明确用途的工具。沿用今天、计划、趋势和设置四个入口，将训练中的操作集中到专注训练模式。提醒默认关闭，不增加账号、社区、商店或在线服务依赖。

## 日常使用的改进

| 环节 | 本轮改动 | 使用方式 |
| --- | --- | --- |
| 快速进入 | 桌面长按应用图标提供称重、训练快捷入口 | 进入当前日期；今天无计划时仍可正常回到首页安排 |
| 称重输入 | 保留斤与公斤自动换算，编辑时选中原数值 | 直接输入新数值，无需逐字删除 |
| 称重微调 | 增减当前单位 0.1，可主动沿用最近一次数值 | 沿用不是自动生成测量，仍须确认保存 |
| 输入核对 | 展示与上次记录之差，近期差异较大时给出非阻断提示 | 不替用户判断增重或减重是否好坏 |
| 防止误退出 | 称重、训练项目表单的返回与外部关闭提示未保存修改 | 明确取消按钮仍表示主动放弃 |
| 新建项目 | 可搜索最近使用与常用动作，类型和目标自动带入编辑 | 不把跑步误建为次数型；所有目标可修改 |
| 复用计划 | 首页可复用最近一次训练，只复制项目目标 | 不复制实际值、勾选状态或旧项目标识 |
| 日期导航 | 周视图外增加完整月历 | 可看训练、休息和称重标记，点击日期进入计划 |
| 页面记忆 | 切换页面保留筛选、日期和滚动位置 | 从设置返回原页面，避免每次回到首页 |

## 边练边记

点击开始或继续训练，进入专注训练模式。次数型项目逐组确认，确认后立刻写入本地数据库；完成全部组后动作变为已完成。勾选过的字段锁定，取消勾选即可修改。

未勾选组的数字仍是待确认草稿，不能当成已完成组统计。批量完成会把用户明确确认的项目全部标记完成，并保留已有实际值；旧版已完成项目升级后视为全部组已确认，旧版进行中项目不猜测已完成组。

| 工具 | 行为 |
| --- | --- |
| 上次记录 | 显示同名同类型动作之前已完成的实际值 |
| 保存草稿 | 保存当前数字，稍后继续 |
| 休息计时 | 勾选非最后一组后按偏好自动开始，固定底部并避开系统导航栏，可暂停、继续、增减 15 秒或结束 |
| 关闭自动计时 | 设置中选择关闭，仍可主动启动 30、60、90 秒手动计时 |
| 进度恢复 | 切换页面、重建 Activity 后读取已保存的组进度；计时按单调时钟恢复，同次开机有效 |
| 保持亮屏 | 仅专注训练模式内生效，可关闭，离开后恢复原设置 |
| 轻触反馈 | 确认训练组时按偏好和系统设置触发，不申请额外震动权限 |
| 退出保护 | 数字修改未保存时可存草稿后离开、继续训练或明确放弃本次输入 |

休息计时是应用内工具，不承诺应用被系统结束后响铃，也不为计时常驻前台服务或持有唤醒锁。切回应用时恢复剩余时间；设备重启后不沿用旧计时。

## 查看进展与外观

趋势图支持轻点和左右拖动查询日期，继续保留真实测量、7 日均值和可选目标线。周统计分别展示称重天数和有已完成动作的训练天数，不将休息日或全部跳过算作完成训练。

支持跟随系统、浅色和深色外观，选择保存在本机。更新自适应桌面图标和独立通知图标，使启动入口、界面和系统通知保持清楚一致。

## 可选每日提醒

称重和训练提醒分别设置时间，默认关闭。只有主动启用时才申请 Android 13 及以上的通知权限。拒绝权限不会阻挡记录、计划和统计。

称重提醒在当天已经记录时抑制；训练提醒仅在当天仍有待完成项目时发送。点击通知进入对应操作。使用系统非精确闹钟，开机、时区或时间变化及应用更新后重新安排；省电限制和厂商行为可能导致延迟，不承诺准点送达。

主题、提醒、亮屏、震动和计时偏好是本机设备设置，不替代备份中的体重、计划、实际与单位设置。

## 备份与找回

- 修改前保留本机恢复点，最多每分钟一个、保留最近 8 个；写入先经过临时文件，再替换为完整文件。
- 恢复点位于应用私有目录，卸载或清除应用数据会删除。换机仍需用户明确导出外部备份。
- 恢复时先校验并展示影响范围，继续要求先导出当前数据，随后单个 Room 事务替换，不能部分覆盖。
- 新完整备份为 schemaVersion 3，新增逐组确认信息，继续接受 v1 和 v2。旧数据库默认补齐新字段，Room 表结构仍为 schema 1。
- 分别导出体重和训练 CSV，使用 UTF-8 BOM，字段明确标出单位和未确认组；重量保留整数克对应的精度。CSV 用于分析，不作为完整恢复格式。

## 本轮边界

本轮完善个人记录工具，不引入自动训练处方、热量和减重预测、社交、设备同步、云账号或付费服务。正式安装包仍可离线使用，提醒是否出现受系统设置与权限影响。验证结果和未完成的机型验证见对应验收记录。
