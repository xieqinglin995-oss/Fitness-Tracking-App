## 升级与数据

以正式版 1.1.1 的模拟验收记录为基础，先通过系统文件选择器导出 v2 JSON，再使用相同签名的 1.2.0 覆盖安装，随后导出 v3 JSON。两份文件均包含 30 条体重、3 日计划、3 条实际记录和 1 个模板。

程序比对完整 `data`，仅移除新版增加的 `completedSets` 字段后逐项相等。旧版已完成次数项目补齐全部确认组，进行中的项目不自动猜测已完成组；单位、目标、备注及原实际值保留。升级不需要删除数据库或卸载。

备份编解码测试覆盖 v1/v2 迁移、v3 逐组确认往返、非法完成索引及状态校验；Room 表结构仍为 schema 1。恢复使用原有先备份、后事务替换流程。

## 验收边界

- 未在用户实际手机上验收性能、字体缩放、厂商文件选择器及后台省电策略。
- Android 13 及以上通知权限流程已实现，但本轮实际设备运行环境为 API 28，未把高版本授权描述为设备实测通过。
- 通知测试确认渠道和应用入口；没有宣称实际等待到每日时刻、经历设备重启或所有厂商后台限制后仍准点通知。每日提醒使用非精确系统调度。
- 休息计时是应用内计时，支持同次开机后的状态恢复，不保证应用被系统结束后响铃。
- 本机恢复点会随卸载或清除数据丢失，CSV 不能替代完整 JSON 备份。新 v3 备份不能供旧版直接恢复。
- 账号、云同步、训练处方、健康平台接入和社交不属于本轮范围。
